# icomers — დოკუმენტაციის საიტი

## გახსნა
- **უბრალოდ სანახავად:** ორჯერ დააწკაპუნეთ `icomers/index.html`-ზე. სერვერი არ სჭირდება. ამ რეჟიმში პასუხები ინახება მხოლოდ იმ ბრაუზერში, და მათი ჩამოტვირთვა მარცხენა მენიუს ბოლოდან შეიძლება.
- **გუნდისთვის (ჰოსტინგი):** სერვერით პასუხები ინახება სერვერზე და ყველასთვის ჩანს.

## როგორ არის აწყობილი
| ფაილი | რა არის |
|---|---|
| `../docs/*.md`, `../docs/diagrams/*.svg` | დოკუმენტაციის წყარო |
| `src/` | გვერდის შაბლონი, სტილი, JavaScript, marked |
| `build.mjs` | ყველაფერს ერთ ფაილად აწყობს: `../index.html` |
| `server.mjs` | ჰოსტინგისთვის: გვერდი + პასუხების API |

დოკუმენტაციის შეცვლის შემდეგ: `node docs-site/build.mjs`. სერვერი გვერდს ყოველ ჩატვირთვაზე ახლიდან აწყობს.

კითხვის დამატება markdown-ში:
```
:::question id="unique-id" to="ადრესატი"
კითხვის ტექსტი
:::
```

## ჰოსტინგი (Docker / usectl)
```bash
docker build -f docs-site/Dockerfile -t icomers-docs .
docker run -p 8080:8080 -v icomers-docs-data:/data icomers-docs
```

| ცვლადი | ნაგულისხმევი | აღწერა |
|---|---|---|
| `PORT` | `8080` | |
| `DATA_DIR` | `/data` | პასუხების ფაილი. საჭიროა მუდმივი დისკი და 1 replica |
| `DOCS_BASIC_AUTH` | — | `user:password`. თუ მითითებულია, საიტი პაროლით იხსნება |

ლოკალურად სერვერით: `node docs-site/server.mjs` → http://localhost:8080

> **usectl-ზე:** აპებს მუდმივი დისკი არ აქვთ, ამიტომ რესტარტისას პასუხების ფაილი დაიკარგება. usectl-ზე ჰოსტინგისთვის პასუხები Postgres ან S3 addon-ში უნდა შეინახოს. ეს ცვლილება საჭიროებისას დაემატება.
